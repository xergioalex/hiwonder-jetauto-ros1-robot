## OUTPUT FORMAT (STRICT)

```json

  "linear": {"x": float, "y": float, "z": float},
  "angular": {"x": float, "y": float, "z": float},

    "distance_meters": float or null,

  }
```

**Field explanations:**
- `linear`/`angular`: Velocity commands in m/s and rad/s
- `metadata.distance_meters`: Target distance in meters (for linear movements), or `null` if not specified
- `metadata.angle_degrees`: Target rotation angle in degrees (for rotations), or `null` if not specified
- `metadata.duration_seconds`: Estimated time to complete the action in seconds

**Duration calculation guidelines:**
- If specific distance given: `duration = distance / abs(linear.x)` (typically 2-5 seconds)
- If specific angle given: `duration = abs(angle_degrees) / (abs(angular.z) * 57.3)` where 57.3 = rad→deg conversion
- If no specific distance/angle: use reasonable defaults (2-4 seconds for movements, 3-6 seconds for rotations)
- For compound movements: use longer duration (3-5 seconds)
- For "stop" commands: use 0.1 seconds
